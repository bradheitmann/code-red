# Contributing to Code Red

Keep the playbook portable. Do not publish local paths, account IDs, credentials,
private incident transcripts, run data, or identifying examples. Public source
citations and the project's public repository/endpoint are intentional.

The skill's canonical text is skills/code-red/. Server resources must use that
text rather than a separately maintained prompt. Keep TypeScript strict and run
the repository checks before release. Preserve existing in-flight contributors'
work and use independent review for changes to operational behavior.

Distinguish historical facts, interpretations, proposed techniques, and measured
results. Do not claim an exhaustive catalog of a thinker's mental models or
guaranteed productivity. Add techniques when they change an operational decision,
with a cheap test and a failure boundary. Keep private run records out of Git.
